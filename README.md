# 🎬 Passarex — Fiu Fiu, 1491

Site do curta-metragem estudantil **"Passarex Fiu Fiu, 1491"**, feito por um grupo de 5 alunos do **IFMS** para a **Categoria A do Festival ZOOM IFMS 2026**.

🔗 **Site:** https://odavyyy.github.io/passarex/
▶️ **Vídeo no YouTube:** https://www.youtube.com/watch?v=_8rrn0imkIQ

## O que tem aqui

| Página | Link | Para quê |
|---|---|---|
| Início | [`/`](https://odavyyy.github.io/passarex/) | Página aberta pelo QR Code do cartaz: mostra o vídeo e pede apoio (curtida + comentário no YouTube, que contam no Apoio Popular) |
| Elenco | [`/elenco/`](https://odavyyy.github.io/passarex/elenco/) | Ficha visual dos personagens do curta (Passarex, Douradex, Tonho, Colombo e a aparição final), todos na mesma escala |

## Como funciona

- Site estático, só HTML + CSS (sem framework), publicado pelo **GitHub Pages** a partir da branch `main`.
- O vídeo é incorporado do YouTube; os botões levam direto pra página do vídeo e para compartilhar.

## Rodar no computador

Basta abrir o `index.html` no navegador (ou usar a extensão *Live Server* do VS Code).
